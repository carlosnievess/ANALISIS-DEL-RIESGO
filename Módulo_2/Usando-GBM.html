\[\sigma_{anual}=\sigma_{diaria}\sqrt{252}\]

¿Por qué por la raíz del tiempo y no solo por el tiempo?

Porque la varianza incrementa de forma más o menos proporcional al tiempo, pero la desviación estándar no.

Estimar \(\mu\)

Recordemos que del GBM, tenemos

\[E[r_{\Delta t}]=(\mu-\frac{1}{2}\sigma^2)\Delta t\]

Entonces despejando

\[\mu=252 r_{diario}+\frac{1}{2}\sigma^2\]

mu_log_anual <- dias_cot*mean_log
mu_log_anual
## [1] 0.132436
mu_gbm_anual <- mu_log_anual+0.5*sigma_anual^2
mu_gbm_anual
## [1] 0.1852083

¿Por qué sumamos el \(\frac{1}{2}\sigma^2\)?

Porque cuando obtenemos el valor esperado de la distribución en logaritmos restamos ese término a la media y debemos por así decirlo regresarlo.

Para cada uno de estos momentos en el tiempo, debemos obtener el valor esperado, el valor mediano y un intervalo de confianza digamos al 95%. Todo esto partiendo de lo que conocemos teóricamente.

Para facilitar este cálculo, haremos una función

gbm_summary <- function(So, mu, sigma, T, nc){
  z_nc=qnorm(1-(1-nc)/2)
  c(
    Precio_Esperado=So*exp(mu*T),
  Mediana=So*exp((mu-0.5*sigma^2)*T),
  Moda=So*exp((mu-0.5*3*sigma^2)*T),
  inferior=So*exp((mu-0.5*sigma^2)*T-z_nc*sigma*sqrt(T)),
  superior=So*exp((mu-0.5*sigma^2)*T+z_nc*sigma*sqrt(T))
  )
}

¿Cómo mejoramos la simulación? Haciendo más simulación

Cada simulación, es decir cada posible valor de S que está en los objetos St_1d, St_1ano, etc corresponde a un posible valor del precio en ese momento. NO SE TRATA DE UNA TRAYECTORIA DE PRECIO

Vamos a construir una trayectoria para un año.

Usaremos ambas ideas, la aproximación con ds y la solución exacta

z2 <- rnorm(252)
n_dias <- 252
dt <- 1/n_dias
S_exacta <- numeric(n_dias+1)
S_apro <- numeric(n_dias+1)
S_exacta[1] <- So
S_apro[1] <- So
for (i in 1:n_dias){
  S_exacta[i+1] <- S_exacta[i]*exp((mu-0.5*sigma^2)*dt+sigma*sqrt(dt)*z2[i])
  S_apro[i+1] <- S_apro[i]+S_apro[i]*mu*dt+sigma*S_apro[i]*sqrt(dt)*z2[i]
}

S_exacta <- S_exacta
plot(S_exacta, type = "l")

plot(S_apro, type = "l")

matplot(cbind(S_apro, S_exacta), type = "l", xlab = "Días de cotización", ylab = "Precio", main = "Sol Exacta vs Aproximación")
